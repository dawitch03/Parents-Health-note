# 부모님 건강검진 수첩

부모님의 국가건강검진·추가 검사·예방접종 일정, 복용 약, 혈압·혈당 같은 건강 수치를 기록하는 웹페이지입니다.
파일 하나(`index.html`)로 동작하고, 서버나 로그인이 필요 없습니다.

## GitHub Pages로 올리기

1. https://github.com/new 에서 새 저장소를 만듭니다 (예: `parents-health-notebook`).
2. 저장소 페이지에서 **Add file > Upload files** 로 `index.html`과 `README.md`를 올리고 **Commit changes**.
3. 저장소 **Settings > Pages** → Source: **Deploy from a branch**, Branch: `main` / `/ (root)` → **Save**.
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/parents-health-notebook/` 에서 열립니다.

## 기록은 어디에 저장되나요?

- 기록은 **페이지를 연 브라우저 안에만** 자동 저장됩니다. GitHub에는 올라가지 않으므로 저장소가 공개여도 건강 기록은 드러나지 않습니다.
- 다른 컴퓨터·휴대폰에서 같은 기록을 보려면 페이지 아래 **백업 파일 저장** → 파일을 옮긴 뒤 다른 기기에서 **백업 불러오기**를 누르세요.
- 브라우저 기록(쿠키·사이트 데이터)을 지우면 기록도 지워집니다. 가끔 백업 파일을 저장해 두세요.
- 시크릿(사생활 보호) 창에서는 창을 닫으면 기록이 사라집니다.
